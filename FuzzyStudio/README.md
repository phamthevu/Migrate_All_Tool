# FuzzyStudio

Practice tools for Spherical Fuzzy, Quantum Spherical Fuzzy, and Neutrosophic Z methods, with a separate VBA code viewer/exporter.

Use the root `requirements.txt` to install the suite dependencies. Shared blank workbooks are in `Templates/Template/FuzzyStudio`; populated examples are in `Templates/Demo Data/FuzzyStudio`. From the suite root, run `FuzzyStudio/run.bat`; to build all apps, run `build_all_windows.bat`.
