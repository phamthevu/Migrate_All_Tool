FuzzyStudio VBA Library

This folder contains the included VBA .bas modules, kept in their original subfolders.
To import into Excel: save your workbook as .xlsm, press Alt+F11, choose File > Import File, and select a .bas file.
Some worksheet functions call helpers in other modules; check VBA Guide for dependencies and import those modules too.
Export full modules from FuzzyStudio > VBA Code, or export the displayed procedure as .txt.
