# DataStudio in the unified suite

DataStudio is maintained as one application folder inside the five-Studio suite. Install dependencies once using the suite-root `requirements.txt`. Run `run.bat` for source mode or run `build_all_windows.bat` from the suite root to build every Studio.

Workbook templates and populated examples are centralized in `Templates/Template` and `Templates/Demo Data`. The build script copies the shared library beside every executable.
