BUILD ALL FIVE STUDIOS (WINDOWS)

Studios
- ResearchStudio: manage research data collection and projects.
- DataStudio: sample data and foundational analyses.
- FuzzyStudio: practice foundational fuzzy methods.
- MCDMStudio: guided numeric practice for foundational MCDM methods.
- MCDMVisualStudio: visualize analysis outputs.

Requirements
- Windows 10/11, 64-bit
- Python 3.10+ and Windows Python Launcher (py)
- Internet for the first dependency install
- Microsoft ODBC Driver 18 only if using ResearchStudio's SQL Server connector

Build
1. Extract the complete source folder. Keep build_all_windows.bat, requirements.txt, and Templates beside the five app folders.
2. Run build_all_windows.bat.
3. Open the matching executable under dist\ResearchStudio, dist\DataStudio, dist\FuzzyStudio, dist\MCDMStudio, or dist\MCDMVisualStudio.

A single root requirements.txt installs the deduplicated dependencies for all five apps and their supported connectors. The batch file builds each app separately and places the shared Templates library beside each executable. Windows builds must be performed on Windows; this workspace is not used to cross-build Windows executables.
