BUILD THE COMPLETE RESEARCH SUITE (WINDOWS)

Apps included
- ResearchStudio: collect and manage research data.
- DataStudio: sample data and foundational analyses.
- FuzzyStudio: practice foundational fuzzy methods.
- MCDMStudio: guided numeric MCDM methods.
- MCDMVisualStudio: visualize analysis results.
- FuzzyStudio also builds the SphericalFuzzy, QuantumSpherical and NeutrosophicZ calculators.

Requirements
- Windows 10/11, 64-bit
- Python 3.10+ and the Windows Python Launcher (`py`)
- Internet access for the first dependency installation
- Microsoft ODBC Driver 18 only when using ResearchStudio's SQL Server connector

Build all apps
1. Extract the full source ZIP. Keep `build_all_windows.bat`, `requirements.txt`, `Templates`, and all five app folders together.
2. Double-click `build_all_windows.bat` and wait for dependency installation, MCDMStudio tests and all PyInstaller builds to finish.
3. Run each app from `dist\APPNAME\APPNAME.exe`. The `Templates` folder beside each app must stay in place.

The script creates a shared `.build-venv`, installs the deduplicated dependencies from the root `requirements.txt`, runs the MCDMStudio deterministic and stress tests, then builds all apps and the three fuzzy calculators. Build output is under `dist\`. Packaged users do not need Python. Windows executables must be built on Windows; this source workspace is not a Windows build host.
